---
title: 'Quick Start'
description: 'Run InboxJarvis locally from source'
---

Start with the [InboxJarvis repository](https://github.com/sv182124/InboxJarvis). You will need Node.js 24, Docker, and the pnpm version pinned in `package.json`.

```bash
git clone https://github.com/sv182124/InboxJarvis.git
cd InboxJarvis
corepack enable
pnpm install
pnpm setup
```

In the setup wizard, choose **Development**, use Docker for PostgreSQL and Redis, and keep the web app running from source. Configure Google or Microsoft OAuth and an AI provider when prompted.

Start only the database services. For the default configuration, run:

```bash
docker compose --env-file apps/web/.env --profile all up -d db redis serverless-redis-http
```

For a named configuration, use its environment-file path and keep the explicit service names `db redis serverless-redis-http`. Then run:

```bash
pnpm --dir apps/web exec prisma migrate deploy
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Setup options

For manual configuration, copy `apps/web/.env.example` to `apps/web/.env`, generate the required secrets, and follow the [Setup Guides](/hosting/setup-guides). Local Google and Microsoft emulators are documented in [Contributing](/contributing).

## Install options

Run this checkout's CLI directly for additional setup commands:

```bash
pnpm exec tsx packages/cli/src/main.ts --help
```

The `@inbox-zero/cli` npm package, Homebrew formula, and prebuilt Inbox Zero images are published by the upstream project. They do not contain this checkout's InboxJarvis changes. No InboxJarvis package or binary release is assumed by these instructions.
