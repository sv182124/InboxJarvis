Use the InboxJarvis API CLI when you want a thin wrapper around the public API for scripts, bots, or local automation.

The package keeps the compatibility name `@inbox-zero/api` and executable name `inbox-zero-api`. Run the version in this repository to use InboxJarvis defaults.

## Run from source

After installing this repository's dependencies, run from its root:

```bash
pnpm exec tsx packages/api/src/main.ts --help
```

Published `@inbox-zero/api` packages are upstream releases and may use a different default server.

## Configure access

The CLI reads configuration in this order:

1. Command flags
2. Environment variables
3. `~/.inbox-zero-api/config.json`

Supported environment variables:

- `INBOX_ZERO_API_KEY`
- `INBOX_ZERO_BASE_URL` for self-hosted or custom API deployments

Example:

```bash
pnpm exec tsx packages/api/src/main.ts rules list
```

`base-url` is optional. The CLI defaults to `http://localhost:3000` and only needs an override for self-hosted or custom deployments.

Set `INBOX_ZERO_API_KEY` in your shell or secret manager before running commands. Avoid passing API keys as CLI arguments because they can leak into shell history and process listings.

## Common commands

List rules:

```bash
pnpm exec tsx packages/api/src/main.ts rules list
pnpm exec tsx packages/api/src/main.ts rules list --json
```

Get a rule:

```bash
pnpm exec tsx packages/api/src/main.ts rules get rule_123 --json
```

Create a rule from JSON:

```bash
pnpm exec tsx packages/api/src/main.ts rules create --file rule.json
cat rule.json | pnpm exec tsx packages/api/src/main.ts rules create --file -
```

Update a rule from JSON:

```bash
cat rule.json | pnpm exec tsx packages/api/src/main.ts rules update rule_123 --file -
```

Delete a rule:

```bash
pnpm exec tsx packages/api/src/main.ts rules delete rule_123
```

Read stats:

```bash
pnpm exec tsx packages/api/src/main.ts stats by-period --period week --json
pnpm exec tsx packages/api/src/main.ts stats response-time --json
```

Unsubscribe from a sender:

```bash
pnpm exec tsx packages/api/src/main.ts senders unsubscribe news@example.com
pnpm exec tsx packages/api/src/main.ts senders unsubscribe news@example.com --json
```

Fetch the live OpenAPI document:

```bash
pnpm exec tsx packages/api/src/main.ts openapi --json
```

For bots, prefer `--json` so the output is stable and machine-readable.
