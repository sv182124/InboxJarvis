title: 'Gmail tabs extension'
description: 'Optional compatibility with the upstream Inbox Zero Tabs extension'
icon: 'chrome'
---

Inbox Zero Tabs is a separate extension maintained by the upstream Inbox Zero project. InboxJarvis does not publish its own browser extension.

The application retains the extension-sync integration and configuration key `NEXT_PUBLIC_TABS_EXTENSION_ID` for compatibility. Confirm the extension you install supports your deployment before using sync.

You can also organize Gmail directly with its **Multiple Inboxes** setting and search queries such as `is:starred`, `label:Newsletter`, or `is:unread`.
