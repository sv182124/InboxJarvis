InboxJarvis exposes a remote MCP server so ChatGPT, Claude, Cursor, or another MCP client can work with your linked Gmail and Outlook accounts.

The assistant can search and read mail, create mailbox drafts, manage automation rules, and read email statistics. It cannot send email. Drafts stay in your mailbox until you send them.

This is different from [Integrations](/essentials/context-integrations), which let InboxJarvis call other products during assistant rules.

## Turn on MCP for your account

1. Open Settings and scroll to **Account → MCP**.
2. Turn on **MCP**.
3. Copy the MCP URL from the connect dialog.

Use this Streamable HTTP URL:

```text
http://localhost:3000/mcp
```

Local clients on this computer can use this address. Cloud-hosted connectors need a reachable HTTPS deployment URL instead.

Self-hosted deployments use `https://your-inboxjarvis-host/mcp` after setting `MCP_SERVER_ENABLED=true`, `NEXT_PUBLIC_EXTERNAL_API_ENABLED=true`, and `API_KEY_SALT`. See the [MCP API reference](/api-reference/mcp).

If MCP is still off when the assistant connects, the consent screen can turn it on for you after you sign in with Google or Microsoft. Email-code sign-in cannot authorize MCP clients.

## ChatGPT

ChatGPT needs a public HTTPS MCP URL and Developer mode. Availability depends on your ChatGPT plan.

1. Open ChatGPT on the web and go to **Settings → Apps**.
2. Turn on **Developer mode**.
3. Create a new app or connector and paste the InboxJarvis MCP URL.
4. Scan tools, then sign in to InboxJarvis and choose **Allow**.
5. Start a new chat and enable the InboxJarvis app from the tools menu before asking it to search mail or draft a reply.

If ChatGPT asks how to authenticate, choose OAuth. Do not paste an InboxJarvis API key.

## Claude

1. Open Claude and go to **Customize → Connectors**.
2. Choose **Add custom connector**.
3. Paste the InboxJarvis MCP URL. Leave OAuth client ID and secret empty unless you registered a client yourself.
4. Add the connector, then choose **Connect** and **Allow** on the InboxJarvis consent screen.
5. In a chat, open **+ → Connectors** and enable InboxJarvis before asking it to search mail or draft a reply.

On Team and Enterprise, an owner adds the connector under **Organization settings → Connectors** first. Members then connect it from **Customize → Connectors**.

### Claude Code

```bash
claude mcp add --transport http inbox-zero http://localhost:3000/mcp
```

Local clients on this computer can use this address. Cloud-hosted connectors need a reachable HTTPS deployment URL instead.

Claude Code then signs you in with OAuth.

## Cursor

Add this to `~/.cursor/mcp.json` or the project `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "inbox-zero": {
      "url": "http://localhost:3000/mcp"
    }
  }
}
```

Cursor then signs you in with OAuth. You can also add the same URL from **Cursor Settings → MCP**. This repository also includes a local Cursor plugin under `plugins/inbox-zero-mcp`.

## What the assistant can do

| Permission | Tools |
| --- | --- |
| Read | List inboxes, search mail, read threads, list rules, read stats |
| Write | Create a draft (does not send), create/update/delete rules |

Ask it to search recent mail, summarize a thread, draft a reply, or update an automation rule. Sending stays in InboxJarvis or your mailbox.

## Disconnect an app

1. Open **Settings → Account → MCP**.
2. Choose **MCP apps**.
3. Disconnect the application you no longer trust.

That revokes only that app. Other connected apps keep working. Turn off **MCP** to disconnect every app at once. Refresh tokens survive logging out of InboxJarvis in the browser; disconnecting or turning MCP off is what revokes them.
